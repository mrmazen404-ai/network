# Network Security Monitor — Hardened Build

هذه النسخة تتضمن إصلاحات أمنية واعتمادية أولية مقارنة بالنسخة الأصلية.

## التشغيل

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

للالتقاط الحي ومسح ARP يلزم تشغيل التطبيق بصلاحيات مناسبة. استخدم الفحص النشط فقط على شبكات تملك تصريحًا لفحصها.

## الإعدادات

انسخ `.env.example` إلى `.env` أو عرّف المتغيرات في بيئة التشغيل. لا تضع مفاتيح EmailJS في الكود أو في Git. EmailJS غير مهيأ افتراضيًا؛ عند غياب الإعدادات، يتوقف إرسال OTP برسالة عامة ولا يتم عرض الرمز.

راجع `PRODUCTION_SETUP_AR.md` لإعداد EmailJS، تدوير المفاتيح القديمة، وتشغيل الإصدار النهائي بدون أسرار أو قاعدة بيانات مرفقة.

الطرفية مقيدة دائمًا إلى أوامر تشخيص شبكي معتمدة وتستخدم `shell=False`. لا يوجد مسار shell حر داخل التطبيق.

## الاختبارات

```bash
pytest -q
```

اختبارات التكامل القديمة في `test_system.py` تحتاج واجهة وبيئة شبكة، بينما الاختبارات الموجودة في `tests/` مصممة لتكون قابلة للإعادة.
